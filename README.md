#Репозиторий International Checkers (Шашки)
Описание
International Checkers – это набор консольных реализаций игры в международные шашки (10×10) на 8 языках программирования. Проект создан как тестовый репозиторий для демонстрации решения одной игровой задачи на разных языках с использованием идиоматичных подходов и продвинутых возможностей.

В игре реализованы все правила международных шашек:

Доска 10×10, начальная расстановка по 20 шашек с каждой стороны.

Простые шашки ходят на одну клетку вперёд по диагонали, бьют назад и вперёд.

Дамка ходит на любое число клеток по диагонали и бьёт на любое расстояние.

Обязательное взятие – если есть возможность побить шашку противника, игрок обязан это сделать.

Многократное взятие – после взятия шашка продолжает бить, если есть возможность.

Превращение в дамку при достижении последней горизонтали (сразу после хода, а если превращение произошло при взятии, то дамка продолжает бить, если возможно).

Победа при уничтожении всех шашек противника или при блокировке.

Программа реализована в режиме человек против компьютера (ИИ использует простую эвристику – случайный выбор из допустимых ходов с приоритетом взятия) или два игрока (по выбору). Доска отображается в консоли с цветовой разметкой, поддерживается ввод ходов в формате a1 b2 (для обычных ходов) и a1 b2 c3 d4 (для серии взятий).

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения.

Язык	Установка	Запуск
Python	Python 3.8+	python checkers.py [опции]
JavaScript	Node.js 14+	node checkers.js [опции]
TypeScript	Node.js + npm install -g ts-node typescript	ts-node checkers.ts [опции]
Go	Go 1.18+	go run checkers.go [опции]
Java	JDK 11+	javac Checkers.java && java Checkers [опции]
C#	.NET SDK 6.0+	dotnet run или csc
PHP	PHP 8.0+	php checkers.php [опции]
Ruby	Ruby 2.7+	ruby checkers.rb [опции]
Использование
text
checkers [options]
Опции
Опция	Описание
--color	Включить цветной вывод (по умолчанию включён, если терминал поддерживает).
--no-color	Отключить цветной вывод.
--two-players	Режим для двух игроков (по очереди).
--save <file>	Сохранять состояние игры в файл после каждого хода (для продолжения).
--load <file>	Загрузить состояние игры из файла.
--help	Показать справку.
Пример
bash
# Игра с компьютером
python checkers.py --color

# Игра двух игроков с сохранением
node checkers.js --two-players --save game.json
Правила игры
Доска 10×10, клетки обозначаются буквами A–J (по вертикали) и цифрами 1–10 (по горизонтали).

Игроки: белые (снизу, ходят первыми) и чёрные (сверху).

Ходы простых шашек: на одну клетку вперёд по диагонали.

Взятие (рубка): если рядом по диагонали стоит шашка противника, а следующая клетка за ней свободна, шашка обязана её побить. Если после взятия появляется новая возможность, взятие продолжается.

Дамка: при достижении последней горизонтали простая шашка превращается в дамку. Дамка ходит на любое число клеток по диагонали и бьёт аналогично.

Обязательность: если есть несколько вариантов взятия, игрок выбирает любой; если есть взятие, ход без взятия запрещён.

Победа: игрок, уничтоживший все шашки противника или лишивший противника возможности хода, объявляется победителем.

Особенности реализаций
Все версии используют объектно-ориентированный подход (классы/структуры для доски, шашек, игрока, ИИ).

Реализована проверка корректности ходов, обязательность взятия, многократное взятие.

ИИ (если режим один игрок) выбирает ход случайно из всех возможных, но отдаёт предпочтение взятию (если есть взятие, выбирает только взятие).

Поддерживается сохранение и загрузка состояния через JSON (или сериализацию).

Цветной вывод (ANSI) для лучшей визуализации.
